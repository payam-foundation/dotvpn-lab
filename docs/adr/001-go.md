# ADR-001: Go

Status: accepted

## Context

One language for every dependency we need.

## Decision

Snowflake, WebTunnel, uTLS, quic-go, gVisor netstack, smux and certmagic are Go libraries and run in-process. Go gives static cross-compiled binaries, trivial bash install, and goroutines suit many long-lived tunnels.

## Rejected

Rust: no Snowflake or WebTunnel libraries, slower iteration, no gain here. Node or Python: footprint, GC under load, packaging.
